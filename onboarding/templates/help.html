LLM keys

Pick whichever model provider you already have a key for. The form defaults to Ollama Cloud — cheapest path to live.

  • Ollama Cloud (default) — sign up at ollama.com, then create a key at ollama.com/settings/keys. Starts with ollama_.
  • Anthropic Claude — get a key at console.anthropic.com. Starts with sk-ant-.
  • OpenAI — platform.openai.com/api-keys. Starts with sk-.

Composio — 5-minute walkthrough

Composio is the OAuth + integration layer SafeClaw uses to reach your Gmail, Drive, and Slack workspace. You do this part on your own machine — SafeClaw never sees your Google or Slack OAuth tokens; Composio holds them and we call Composio's MCP servers to act on your behalf.

The output of this walkthrough is four strings you'll paste into Step 2 of the setup form: COMPOSIO_API_KEY, COMPOSIO_USER_ID, COMPOSIO_READER_MCP_URL, COMPOSIO_ACTOR_MCP_URL.

  1. Sign up at app.composio.dev — the free tier is plenty for getting started.
  2. Initialize a Composio dev context. In any local directory on your machine, run: 
    composio dev init
    This writes .env.local with your ak_ API key. (Don't have the CLI? npm i -g composio-cli@latest first.) The same key is also visible at app.composio.dev/settings/api-keys. Save it — this is your COMPOSIO_API_KEY.
  3. Connect Gmail. In the Composio dashboard: + Add Connection → Gmail → complete the OAuth flow with your Google account. The dashboard will show a user_id for this connection — save it as your COMPOSIO_USER_ID.
  4. Connect Drive and Slack the same way. Use the SAME user_id for all three connections so a single MCP server can reach all of them.
  5. Create the Reader MCP server. Composio dashboard → MCP Servers → Create new. Give it a name like safeclaw-reader and add EXACTLY these tools (read-only boundary — do not add any write tools here):
    • GMAIL_FETCH_EMAILS
    • GMAIL_LIST_THREADS
    • GMAIL_GET_PROFILE
    Save and copy the URL.
  6. Create the Actor MCP server. Same flow, name it safeclaw-actor, and add EXACTLY these tools (the write boundary — can draft / send but cannot read raw inboxes):
    • GMAIL_CREATE_EMAIL_DRAFT
    • GMAIL_REPLY_TO_THREAD
    • SLACK_SEND_MESSAGE
    Save and copy the URL. Drive uploads are handled by a local service account configured in Step 5 — not via Composio.
  7. Critical: append /mcp?user_id=<your_user_id> to each MCP URL before pasting it into the form. Composio's dashboard shows you the BASE URL only; you have to add the /mcp?user_id=... suffix yourself. Final URLs look like: 
    https://backend.composio.dev/v3/mcp/<mcp-id>/mcp?user_id=<your-user-id>
  8. Paste the four values into Step 2 of the setup form and click Next. The webapp validates the API key (one cheap call to backend.composio.dev/api/v3/toolkits) and lists the tools on each MCP server before submission — you'll see an error there if anything's wrong, before any containers boot.

Why split Reader and Actor? It's a security boundary: a bug in the actor agent cannot exfiltrate your raw inbox because it doesn't have that tool. A bug in the reader cannot send mail. The split is the whole reason SafeClaw can hold customer data without us pretending "trust the model."

Slack app — 10-step walkthrough

  1. Go to api.slack.com/apps and click Create New App → From scratch.
  2. Pick a name (e.g. SafeClaw) and your workspace. Click create.
  3. In the left sidebar, open Socket Mode and toggle it ON. Generate an App-level token with the connections:write scope. Copy the xapp-... token — this is your App Token.
  4. Open OAuth & Permissions. Under Bot Token Scopes, add: app_mentions:read, channels:history, chat:write, commands, im:history, im:write, users:read.
  5. At the top of the same page, click Install to Workspace. Approve. Copy the xoxb-... token — this is your Bot Token.
  6. Open Event Subscriptions, toggle ON. Under Subscribe to bot events, add: app_mention, message.channels, message.im.
  7. Open App Home. Enable the Messages tab and check "Allow users to send Slash commands and messages from the messages tab".
  8. In Slack, click your workspace name → Settings & administration → Workspace settings. Find the Workspace ID (starts with T) in the URL of the admin page.
  9. To find your User ID (starts with U): click your avatar → Profile → the ... menu → Copy member ID.
  10. Invite the bot to each channel you want it to listen in: /invite @SafeClaw. Then right-click each channel → Copy link and pull the channel ID (starts with C) out of the URL.

Telegram (optional)

Skip this whole section if you only want Slack.

  1. On Telegram, message @BotFather with /newbot. Pick a name and username.
  2. Copy the token BotFather gives you. Looks like 123456:ABC-DEF....
  3. Message @userinfobot to find your numeric Telegram user ID.
  4. Paste both into the form. Telegram is boss-only by design — only IDs you list here can talk to the bot.

Troubleshooting

"Composio rejected the API key"

Most often this means you pasted the key with extra whitespace, or you regenerated the key in the dashboard after copying. Open app.composio.dev/settings/api-keys, copy a fresh one, and try again. The key starts with ak_.

"Reader/Actor MCP returned no tools"

This means the user_id in your MCP URL doesn't match the user_id that owns the Gmail/Drive/Slack connections. Re-check that the MCP URL ends with /mcp?user_id=<same id you connected Gmail under>. The Composio dashboard sometimes shows the URL without the /mcp?user_id= suffix — you have to add it yourself.

"Slack rejected the bot token"

Re-run the install-to-workspace step. The bot token only becomes valid AFTER the install. The first xoxb-... Slack shows you in the OAuth page is a draft until you click install.

The progress bar is stuck on "Bootstrapping brain"

This step pulls the last 90 days of email through the Reader MCP and embeds every message. On a busy inbox it can take 5-10 minutes. Check docker compose logs embedder to see live progress.

I refreshed the page mid-install

Your install ID is in the URL. Visit /progress/<id> to rejoin the SSE stream. If the webapp container restarted, you'll need to retry from the form.
