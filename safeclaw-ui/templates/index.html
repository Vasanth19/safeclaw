Slack

Socket-mode bot — no public URL needed.

Set up from manifest (recommended — one paste, all scopes pre-configured)
  1. Go to api.slack.com/apps → Create New App → From a manifest. Use your own / dev workspace, never a client's.
  2. Pick the workspace → switch to the JSON tab → paste the manifest below → Create.
  3. Socket Mode → generate an App-Level Token (scope connections:write) → this is xapp-….
  4. Install to Workspace → copy the Bot Token (xoxb-…). In Slack, /invite the bot to channels it should read.

Telegram

      
Long-polling bot — chat from your phone.

      

        
How to get a bot token

        
    
          
  1. In Telegram, open @BotFather → send /newbot.
    2. 
          
  2. Give a name + a username ending in bot (e.g. mark_safeclaw_bot).
    3. 
          
  3. Copy the token it returns (123456:AAH…).
    4. 
          
  4. Get your numeric ID: message @userinfobot → it replies with your Id.
    5. 
        

        
⚠️ Use a fresh bot for this box — a bot running elsewhere will conflict (one listener per bot).

      

      

        
        
        
      

    


    
    

      
Gmail

      
Via Composio. Reader = read-only, Actor = draft-only. The trust split is enforced here — the agent can never send. Auto-provisions both MCP servers.

      

        
How to connect

        
    
          
  1. Sign in at app.composio.dev.
    2. 
          
  2. In Composio, connect your Gmail account (OAuth) so the tools are authorized.
    3. 
          
  3. Copy your API key (ak_…) and note your user id.
    4. 
          
  4. Paste both below → Connect & provision. SafeClaw creates the Reader (read) + Actor (draft) MCP servers automatically.
    5. 
        

      

      

        
        
        

        
        
Each selected account is wired separately (read-only → Reader, draft-only → Actor). Multiple Gmails stay distinct — routed by connected-account id, so they never overwrite each other.

How to get the key

        
    
          
  1. Google Cloud Console → pick/create a project → Enable APIs → enable Google Drive API.
    2. 
          
  2. IAM & Admin → Service Accounts → Create service account.
    3. 
          
  3. Open it → Keys → Add key → JSON → download the file.
    4. 
          
  4. In Drive, share your target folder with the service account's client_email (Editor).
    5. 
          
  5. Paste the full JSON below → Save.

Zapier / MCP Servers

      
Add any MCP server by URL — Zapier MCP exposes thousands of app actions through one endpoint. (For Gmail, prefer the Composio panel — it enforces the trust split.)

      

        
How to add a Zapier MCP

        
    
          
  1. Go to mcp.zapier.com → create an MCP server, pick the actions you want exposed.
    2. 
          
  2. Copy the generated MCP URL (https://mcp.zapier.com/api/mcp/s/…).
    3. 
          
  3. Name it + paste the URL below → Add. It registers instantly and appears on the Dashboard.
    4. 
        

        
Any OpenAI/MCP-compatible server URL works here, not just Zapier.
