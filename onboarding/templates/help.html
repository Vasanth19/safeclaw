LLM keys

Pick whichever model provider you already have a key for. The form defaults to Ollama Cloud — cheapest path to live.

  • Ollama Cloud (default) — sign up at ollama.com, then create a key at ollama.com/settings/keys. Starts with ollama_.
  • Anthropic Claude — get a key at console.anthropic.com. Starts with sk-ant-.
  • OpenAI — platform.openai.com/api-keys. Starts with sk-.

Slack app — 10-step walkthrough

  1. Go to api.slack.com/apps and click Create New App → From scratch.
  2. Pick a name (e.g. SafeClaw) and your workspace. Click create.
  3. In the left sidebar, open Socket Mode and toggle it ON. Generate an App-level token with the connections:write scope. Copy the xapp-... token — this is your App Token.
  4. Open OAuth & Permissions. Under Bot Token Scopes, add: app_mentions:read, channels:history, chat:write, commands, im:history, im:write, users:read.
  5. At the top of the same page, click Install to Workspace. Approve. Copy the xoxb-... token — this is your Bot Token.
  6. Open Event Subscriptions, toggle ON. Under Subscribe to bot events, add: app_mention, message.channels, message.im.
  7. Open App Home. Enable the Messages tab and check "Allow users to send Slash commands and messages from the messages tab".
  8. In Slack, click your workspace name → Settings & administration → Workspace settings. Find the Workspace ID (starts with T) in the URL of the admin page.
  9. To find your User ID (starts with U): click your avatar → Profile → the ... menu → Copy member ID.
  10. Invite the bot to each channel you want it to listen in: /invite @SafeClaw. Then right-click each channel → Copy link and pull the channel ID (starts with C) out of the URL.

Telegram (optional)

Skip this whole section if you only want Slack.

  1. On Telegram, message @BotFather with /newbot. Pick a name and username.
  2. Copy the token BotFather gives you. Looks like 123456:ABC-DEF....
  3. Message @userinfobot to find your numeric Telegram user ID.
  4. Paste both into the form. Telegram is boss-only by design — only IDs you list here can talk to the bot.

Troubleshooting

"Composio credentials not preloaded"

This means the operator who provisioned your VPS forgot to set up Composio before sending you the URL. Email them — the fix is for them to re-run provision-vps.sh with the four COMPOSIO_* env vars set. There's nothing you can do from the form to recover.

"Slack rejected the bot token"

Re-run the install-to-workspace step. The bot token only becomes valid AFTER the install. The first xoxb-... Slack shows you in the OAuth page is a draft until you click install.

The progress bar is stuck on "Bootstrapping brain"

This step pulls the last 90 days of email through the Reader MCP and embeds every message. On a busy inbox it can take 5-10 minutes. Check docker compose logs embedder to see live progress.

I refreshed the page mid-install

Your install ID is in the URL. Visit /progress/<id> to rejoin the SSE stream. If the webapp container restarted, you'll need to retry from the form.
