    Instructions

    1. LLM Provider Setup

    Choose the model provider for your assistant's intelligence.

    Ollama Cloud (Fastest)

    1. Go to ollama.com/settings/keys
    2. Sign in and generate a new API key.
    3. Copy the key starting with ollama_.

    Anthropic Claude

    1. Log in to console.anthropic.com
    2. Go to Settings → API Keys.
    3. Generate a key starting with sk-ant-.

    OpenAI GPT-4o

    1. Log in to platform.openai.com
    2. Go to Dashboard → API keys.
    3. Generate a key starting with sk-.

    View full LLM help →

    2. Composio (Google Auth)

    Composio securely handles your Gmail and Drive connections.

    1. Sign up: Create an account at app.composio.dev.
    2. Connect Tools: Go to Tools in the sidebar.
      • Add Gmail (Connect your Google account).
      • Add Google Drive (Same account).
    3. Get API Key: Navigate to Settings → API Keys and copy your ak_... key.
    4. User ID: This can be your email or any unique string you used when connecting tools. SafeClaw uses this to group your connections.

    SafeClaw will automatically provision the necessary MCP servers once you submit the form.

    View 5-minute walkthrough →

    3. Slack Native Bot

    The fastest way to set up Slack is to use an App Manifest.

    1. Create: Go to api.slack.com/apps → Create New App → From Manifest.
    2. Select your workspace, then paste this JSON into the JSON tab:
    { "display_information": { "name": "SafeClaw" }, "features": { "app_home": { "home_tab_enabled": true, "messages_tab_enabled": true, "messages_tab_read_only_enabled": false }, "bot_user": { "display_name": "SafeClaw", "always_online": true } }, "oauth_config": { "scopes": { "bot": [ "app_mentions:read", "channels:history", "channels:read", "chat:write", "chat:write.public", "commands", "groups:history", "groups:read", "im:history", "im:read", "im:write", "mpim:history", "mpim:read", "reactions:read", "reactions:write", "users:read", "users:read.email" ] } }, "settings": { "event_subscriptions": { "bot_events": [ "app_mention", "message.channels", "message.groups", "message.im", "message.mpim" ] }, "org_deploy_enabled": false, "socket_mode_enabled": true, "is_hosted": false, "token_rotation_enabled": false } }
    1. Install: Sidebar → Install App. Install to workspace and copy the Bot User OAuth Token (xoxb-...).
    2. Socket Mode: Sidebar → Basic Information. Scroll down to App-Level Tokens and copy your xapp-... token (scope: connections:write).
    3. Admin ID: In Slack, click your Profile → More (...) → Copy member ID. This ID (U...) will be the only one allowed to approve email sends.

    View 10-step walkthrough →

    4. Telegram Pocket Assistant

    Optional: Control your assistant from Telegram.

    1. Message @BotFather: Open t.me/BotFather.
    2. Create Bot: Send /newbot and follow instructions to get your API Token.
    3. Get Your ID: Message t.me/userinfobot to find your numeric User ID. SafeClaw uses this to ensure only you can talk to the bot.
